# Order Tracking Screen

A mobile-first order tracking UI built with Next.js and Tailwind CSS.

## Live Demo

[https://order-tracking-screen-kohl.vercel.app/Delayed](https://order-tracking-screen-kohl.vercel.app/Delayed)

## Screens

- **Delayed** — Shows a delayed delivery with progress timeline and alert
- **Not Received** — Shows a delivered-but-not-received state with report options
- **No Tracking** — Shows an order with no tracking info yet and a status checklist

## Tech Stack

- Next.js 15 (App Router)
- Tailwind CSS v4
- React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects automatically to `/Delayed`.
